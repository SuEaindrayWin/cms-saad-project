# Complaint Management System (CMS)

This repository contains architecture and design artefacts for the
Software Architecture and Design (SAAD) coursework.

## Project Overview
The Complaint Management System (CMS) is a multi-tenant platform designed
for large banking and telecommunications organisations to manage the
full lifecycle of customer complaints.

## Architecture
- Architecture style: Modular Monolith
- Backend: Node.js with Express
- Frontend: React
- Database: PostgreSQL
- Authentication: JWT-based with role-based access control

## Repository Structure
- ADRs: Architecture Decision Records
- diagrams: Architecture and design diagrams
- docs: Additional documentation

## Notes
This repository contains design artefacts and a partial proof of concept
intended to support architectural decisions rather than a full production system.
